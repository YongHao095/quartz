## 概述

经典条件作用，由俄国生理学家**伊万·巴甫洛夫**在 19 世纪末研究狗的消化现象时偶然发现并系统阐述。

一个原本中性的刺激，通过与一个能自然引发反应的刺激反复配对出现，最终变得能够单独引发该反应。

## 形成

| 核心概念 | 描述 | 在实验中的体现 |
| :--- | :--- | :--- |
| **无条件刺激** | 能**自然、自动**引发某种反射性反应的刺激。 | **食物** |
| **无条件反应** | 由无条件刺激**自然引发**的、无需学习的反射性反应。 | **分泌唾液** |
| **中性刺激** | 在条件作用发生前，**无法**引发无条件反应的刺激。 | **铃声**（在实验初期） |
| **条件刺激** | 通过与无条件刺激反复配对，**后天习得**了引发反应能力的中性刺激。 | **铃声**（在与食物反复配对后） |
| **条件反应** | 由条件刺激**后天习得**的反应。 | **听到铃声就分泌唾液** |

**实验过程**：

1. 前条件作用：铃声（中性刺激）→ 无唾液分泌。
2. 习得过程：铃声（中性刺激） + 食物（无条件刺激）→ 分泌唾液（无条件反应）。
3. 条件作用形成：铃声（条件刺激）→ 分泌唾液（条件反应）。

## 规律

1. **习得**：在条件刺激与无条件刺激之间建立联结的过程叫做条件反射的习得过程
2. **消退**：条件反射形成以后，如果重复出现，不伴随无条件刺激，得不到强化，会逐渐削弱直至消失
3. **自然恢复**：在消退过程后，经过一段休息或间歇期，条件反应可能会在条件刺激单独出现时短暂地再次出现。
4. **泛化**：在条件作用形成后，与条件刺激**相似**的其它刺激也能诱发条件反应。
5. **分化**：个体学会只对特定的条件刺激做出反应，而对其他相似刺激不予反应。

## 应用

1. **解释恐惧症与焦虑的形成**：华生的小阿尔伯特实验证明，恐惧可以通过经典条件作用习得。一个中性刺激（白鼠）与一个令人恐惧的无条件刺激（巨大的噪音）配对，会变成引发恐惧的条件刺激。
2. **广告与营销**：将产品（中性刺激）与美好的画面、音乐或名人（无条件刺激）配对，使产品本身就能引发积极的情绪（条件反应）。
3. **药物耐受与成瘾**：与环境线索（条件刺激）相关的身体反应（条件反应）会抵消药物的预期效果，导致使用者需要更大剂量，从而形成耐受性。
4. **心理治疗**：基于消退原理的**暴露疗法**，通过让患者反复接触恐惧的刺激（条件刺激）而不发生负面后果，来消除其恐惧反应（条件反应）。

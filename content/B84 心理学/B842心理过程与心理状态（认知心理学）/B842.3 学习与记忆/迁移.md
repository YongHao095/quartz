## 概述

迁移指人们在一种情境中所获得的 [知识](../../../../G%20文体教育/G2%20信息与知识传播/G25%20图书馆学，图书馆事业/G252%20读者工作/G252.7%20文献检索/G252.7文献检索与利用/知识.md) 或技能可以影响到随后[学习](学习.md)的另一种知识和技能。

## 分类

### 按迁移效果分

- 正迁移：已经掌握的知识或技能对学习新知识或技能的积极影响。如会 java 再学 Python。
- 负迁移：已经掌握的知识或技能对学习新知识或技能的消极影响或干扰。如会打网球学羽毛球 (对动作细节不同)

### 按学习情景分

- 近迁移：先前的学习情景 (内容，方式) 与后来学习情景非常相似。如学会发动机原理去学构造。
- 远迁移：先前学习的情景与后来学习的情景有联系，但区别很大。如学会经济原理去炒股。

### 按意识程度分

- 有意迁移：学习者在学习过程中有意识的进行抽象概括和反思总结。寻找当前情景与新情景的联系和相似性，从而在新情景下产生的迁移。学完 java 学 Python。
- 无意迁移：学习者在学习过程中没有有意识的进行总结和反思，而是对学习情景的表面特征产生自动化反应，在新情景下原有的概念技能产生自动化的迁移。如文化素养渗透到方方面面。

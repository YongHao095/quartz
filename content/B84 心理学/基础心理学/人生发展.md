## 概述

个体发展是个体一生中在生理，认知，社会化等方面的变化。既是一个连续的过程，也可以分为不同的阶段。

- [社会性发展](社会性发展.md)

## 阶段

| 时期              | 时间段     |
| :-------------- | :------ |
| [胎儿期](胎儿期.md)   | 0-1.5 岁 |
| [婴幼儿期](婴幼儿期.md) | 1.5-3 岁 |
| [儿童期](儿童期.md)   | 3-6 岁   |
| 学龄期             | 6-12 岁  |
| 青春期             | 12-20 岁 |
| 成年期             | 20-40 岁 |
| [中年期](中年期.md)   | 40-65 岁 |
| [老年期](老年期.md)   | 65 岁以上  |

## 影响因素

- 生理因素，认知能力受到遗传因素的影响。
- 物质环境和社会环境会影响个体发展。

## 研究方法

- 纵向研究法：在一段时间内追踪研究相同的被试的研究方法。
- 横断研究法：在同一时间内研究不同年龄被试，每一个年龄组都叫做一个群体。
- 群体 - 连续研究法：首先在同一时间选定不同的群体进行研究，然后再对各个群体进行纵向追踪研究。

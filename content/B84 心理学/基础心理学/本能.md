## 概述

本能是在进化过程中形成由遗传固定下来的一种不学而能的行为模式，是人类行为的原动力。

## 麦独孤的 18 种主要本能

麦独孤在其著作中详细阐述了 18 种主要的人类本能，每一种都与一种核心情绪相关联。

| 人类本能 | 描述及伴随情绪 |
| :--- | :--- |
| 逃跑本能 | 在危险面前引发逃离行为，以保存自我。（恐惧） |
| 拒绝本能 | 对有害或令人不快的刺激物（如腐烂味道）产生排斥和驱逐行为。（厌恶） |
| 好奇本能 | 对新奇事物或环境产生注意、调查和探索行为。（惊奇、好奇） |
| 好斗本能 | 在遇到阻碍或威胁时，产生攻击和争斗行为。（愤怒） |
| 自卑本能 | 在强者或权威面前产生退缩、顺从和被动行为。（自卑感、服从） |
| 自我肯定本能 | 在社交中表现自己，渴望获得认可、声望和支配感。（自负、支配感） |
| 父母性本能 | 抚育、关爱和保护后代或弱者的行为。（柔情、关爱） |
| 繁殖本能 | 追求异性并进行求偶与交配的行为。（性爱、欲望） |
| 合群本能 | 寻求与他人相伴，害怕孤独，渴望成为群体一员。（孤独感、归属感） |
| 获取本能 | 收集、占有、囤积物品和财产的冲动。（占有感） |
| 建造本能 | 创造、建造、组合事物的冲动和行为。（创造欲） |
| 食欲本能 | 寻求和摄入食物与饮水的行为。（饥饿感、渴感） |
| 笑本能 | 在特定情境（如被搔痒、社交嬉戏）下产生 laughter 的反应。（愉悦感） |
| 舒适本能 | 寻求身体舒适的状态，在不适时调整姿势或位置。（舒适感） |
| 休息和睡眠本能 | 在疲劳时引发休息、松懈和睡眠的需求。（疲惫感） |
| 求助本能 | 在痛苦或困境中向他人发出求救信号，如婴儿的啼哭。（无助感） |
| 移情本能 | 对他人的情绪状态，尤其是痛苦和快乐，产生共鸣并做出反应。（同情） |
| 暗示感受性本能 | 倾向于接受他人的信念、意见和建议，特别是来自权威者的。（易受暗示性） |

## 概述

明尼苏达多相人格测验，简称 MMPI，是世界上最常引用于人格评估和**精神病理学**诊断的标准化量表之一。由美国明尼苏达大学的心理学家哈瑟韦和精神科医生麦金利于 20 世纪 40 年代初期编制。

## 量表结构

MMPI 的结果主要通过一系列量表来解读，分为效度量表和临床量表两大类。

### 效度量表

用于评估测验结果的有效性、可信度及被试的态度。

| 量表 | 英文缩写 | 作用与解读 |
| :--- | :--- | :--- |
| **疑问量表** | ? | 无法回答或未作答的题目数。过多（>30）可能表示回避、困惑或阅读能力差。 |
| **说谎量表** | L | 检测被试是否试图**粉饰自己**，呈现一个过分完美的形象。高分表示防御性强、不坦诚。 |
| **诈病量表** | F | 检测被试是否**夸大问题**、故意 " 装坏 " 或存在严重精神紊乱。由一些不寻常的回答构成。 |
| **校正量表** | K | 检测一种更**精巧的防御态度**。高分表示否认问题、有戒备心；低分可能表示过度自我批评或坦白。 |

### 临床量表

用于评估不同的人格特质和精神病理学症状。

| 量表编号与名称     | 英文缩写 | 高分者典型特征（简要）                    |
| :---------- | :--- | :----------------------------- |
| **疑病**      | Hs   | 过度关注身体健康，疑病倾向，诉说多种躯体不适。        |
| **抑郁**      | D    | 情绪低落、悲观、绝望、缺乏行动动力。             |
| **癔症**      | Hy   | 遇到压力时出现躯体症状，天真、否认心理问题，人际关系不成熟。 |
| **病态人格**    | Pd   | 蔑视社会规范，冲动、叛逆、人际关系肤浅、法律问题。      |
| **男子气 - 女子气** | Mf   | 测量与传统性别角色的认同程度（男/女版本不同）。       |
| **偏执**      | Pa   | 多疑、敏感、关系观念、可能抱有怨恨。             |
| **精神衰弱**    | Pt   | 焦虑、强迫思维、恐惧、紧张、自责。              |
| **精神分裂**    | Sc   | 思维古怪、感知异常、社会疏离、可能存在现实检验能力受损。   |
| **轻躁狂**     | Ma   | 精力过剩、冲动、情绪高涨、想法飘忽、行为轻率。        |
| **社会内向**    | Si   | 社交退缩、害羞、内向、缺乏自信。               |

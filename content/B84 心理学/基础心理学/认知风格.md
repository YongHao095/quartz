## 概述

认知风格是在对事物现象或人进行认识的过程中，个人偏爱使用的信息加工方式。是 [人格](人格.md) 差异在 [认知](认知.md) 方式上的反映。

## 主要类型与模型

### 场依存型 - 场独立型

由赫尔曼·威特金提出，是最著名和研究最广泛的认知风格维度。主要表现在人对外部环境 (场) 的不同依赖程度。

| 维度 | 场依存型 | 场独立型 |
| :--- | :--- | :--- |
| **感知特征** | 知觉易受周围视觉场的影响，难以从背景中分离出主体。 | 不易受周围视觉场干扰，能轻松地从背景中分辨出主体。 |
| **认知特征** | 倾向于从整体上看待事物，善于把握全局。 | 倾向于分析事物的组成部分，喜欢将整体分解。 |
| **社会特征** | 对社会线索更敏感，人际交往技能高，喜欢并善于与人相处。 | 更独立，对社会线索不敏感，人际交往技能相对较弱。 |
| **学习偏好** | 喜欢结构严密的教学，需要明确的外部指导和反馈。 | 喜欢结构不严密的教学，善于自主学习，自我激励。 |
| **典型职业** | 教育、销售、咨询、人力资源等社会性强的领域。 | 科学、工程、数学、建筑等分析性强的领域。 |

### 沉思型 - 冲动型

由杰罗姆·卡根提出，关注个体在不确定情境下做出决策的速度和准确性。

| 维度 | 沉思型 | 冲动型 |
| :--- | :--- | :--- |
| **反应速度** | 慢，倾向于在深思熟虑后做出回答。 | 快，倾向于迅速做出反应，不假思索。 |
| **反应准确性** | 高，错误率较低。 | 低，容易犯错。 |
| **问题解决策略** | 全面考虑各种可能性，权衡利弊。 | 急于求成，考虑不周全。 |
| **教育意义** | 在需要精细分辨和推理的任务上表现更好。 | 可能需要训练其延迟满足和审慎思考的能力。 |

### 整体型 - 分析型

达斯等人根据脑功能的研究提出，关注个体组织和处理信息的策略。

| 维度 | 整体型 | 分析型 |
| :--- | :--- | :--- |
| **信息组织** | 倾向于将信息组织成整体或完形，关注主题和联系。 | 倾向于将信息分解为部分，关注细节和逻辑结构。 |
| **思维方式** | 发散思维，跳跃性强，富于联想。 | 聚合思维，序列性强，逻辑严谨。 |
| **表达方式** | 写作或表达时可能同时涉及多个主题，结构灵活。 | 写作或表达时逻辑层次分明，循序渐进。 |

### 聚合思维型 - 发散思维型

由吉尔福特提出，源于智力结构理论。

| 维度 | 聚合思维型 | 发散思维型 |
| :--- | :--- | :--- |
| **问题解决** | 针对有明确唯一答案的问题，运用逻辑规则找到最佳方案。 | 针对开放性问题，产生多种多样的、新颖的想法和解决方案。 |
| **思维特征** | 求同、规范、逻辑性强。 | 求异、创新、灵活性强。 |
| **典型代表** | 科学家、工程师。 | 艺术家、广告策划人。 |

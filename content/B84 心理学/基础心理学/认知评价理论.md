## 概述

拉扎勒斯认为，情绪的产生来自于个体与环境之间的相互作用，并且认知评价是情绪产生的必要条件和核心过程。对事件的解读（评价）决定了你的情绪。

## 层次

- 初级评价：原确定刺激事件与自己是否有利害关系，以及这种关系的程度。评价为好，则产生积极情绪。
- 次级评价：评估自己可用的应对选项和资源。能否控制刺激事件以及控制的程度。如面对强大的对手，评价为无法对抗，产生恐惧情绪。
- 再评价：个体根据新的信息或环境变化，对先前的事件评价进行修正和调整。这是一个反馈和循环的过程。如对待批评而愤怒，实则在帮你，情绪转变为感激。

## 核心主题与具体情绪

拉扎勒斯指出，不同的具体情绪源于对不同 " 核心主题 " 的认知评价。

| 情绪 | 核心主题（评价的内容） |
| :--- | :--- |
| 愤怒 | 对一个可指责的侮辱或不公正事件的体验。 |
| 恐惧 | 面对一个即时的、具体的、势不可挡的物理或心理威胁。 |
| 悲伤 | 体验到了无法挽回的丧失。 |
| 内疚 | 意识到自己违背了一个道德规范。 |
| 羞愧 | 未能实现理想的自我。 |
| 嫉妒 | 渴望得到他人所拥有的东西，并希望对方失去它。 |
| 自豪 | 通过对有价值的对象或成就的认同，使自我形象得到提升。 |
| 感激 | 确认他人为自己带来了宝贵的利益。 |

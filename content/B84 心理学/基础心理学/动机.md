## 概述

动机是对人的行为的激发，维持和指引，使行为朝向某一目标进行的内部动力。

## 功能

- 激活功能：具有发动行为，推动个体产生某种活动，使个体由静止状态转向活动状态的功能。
- 指向功能：能将行为指向一定的对象或目标。如在学习动机下指向会去教室。
- 维持功能：个体的活动与预期的目标一致，使动机可以维持下去。

## 理论

### 本能理论

人类的所有行为都是以 [本能](本能.md) 为基础的，本能是人类一切思想和行为的基本源泉与动力。

### 驱力理论

驱力理论认为个体由于生理需要，而产生一种紧张状态，激发或驱动个体的行为以满足需要，消除紧张，从而恢复机体的平衡状态，这就是驱力。

### 唤醒理论

唤醒理论认为人们总是处在唤醒状态，希望维持一种生理激活的最佳水平。

- 人们偏好最佳的唤醒水平。
- 重复进行的刺激能使唤醒水平降低。
- 个体经验越高对于偏好越复杂。

### 诱因理论

诱因是指满足个体需要的刺激物，具有激发和诱使个体朝着目标的作用，有积极和消极之分。

诱因是由外在目标激发的，只有变成个体内在的需要，才能推动个体的行为，并具有持久的推动力。

### 逆转理论

逆转理论认为人们的心理需要是对立的，有四对相反的元状态，进而有不同的动机模式。该理论试图解释人的动机状态是如何从一端向另一端转化的。

#### 四对元动机状态对

| 状态一                                                                   | 状态二                                                                       |
| :-------------------------------------------------------------------- | :------------------------------------------------------------------------ |
| **目标导向状态**                                                            | **超越导向状态**                                                                |
| - 关注未来的目标、成就和准备。<br>- 感到焦虑（当未达成目标时）或放松（当达成目标时）。<br>- 行为是达成目标的手段。      | - 关注当下的活动本身和内在体验。<br>- 感到无聊（当唤醒度过低时）或兴奋（当唤醒度适中或偏高时）。<br>- 行为是为了活动本身带来的乐趣。 |
| **顺从状态**                                                              | **逆反状态**                                                                  |
| - 愿意遵守规则、规范和社会期望。<br>- 感到安全感（当遵守时）或愧疚感（当违反时）。<br>- 行为是 " 应该做 " 的事。    | - 渴望打破规则、追求自由和个人控制感。<br>- 感到压抑（当被控制时）或叛逆的快感（当打破规则时）。<br>- 行为是 " 我想做 " 的事。 |
| **掌控状态**                                                              | **共情状态**                                                                  |
| - 渴望控制环境、他人并体验力量感。<br>- 感到骄傲（当成功时）或羞辱（当失败时）。<br>- 关注竞争、权力和 dominance。 | - 渴望与他人和谐相处、沟通并感受关怀。<br>- 感到温情（当连接成功时）或怨恨（当连接失败时）。<br>- 关注合作、分享和同情。       |
| **自我中心状态**                                                            | **他人中心状态**                                                                |
| - 将自我利益和感受放在首位。<br>- 在互动中更关注自己的得失和形象。<br>- 感到自私的满足或个人的损失。             | - 将他人或群体的利益和感受放在首位。<br>- 在互动中更关注他人的需要和反应。<br>- 感到利他的满足或为他人的不幸感到难过。        |

## 概述

面部表情是所有面部肌肉变化组成的模式。能精细的表达不同性质的情绪。不同部位具有不同的表情作用，如眼睛对表达忧伤重要。

## 面部表情模式

汤姆金斯假定有八种原始情绪，并每种情绪都有相应的面部表情模式。

| 情绪    | 面部表情模式描述（核心特征）            |
| :---- | :------------------------ |
| 兴趣    | 眉毛略微下垂，眼睛追踪、注视、聚焦，嘴唇微张。   |
| 愉快    | 微笑，嘴角上扬并向后拉，眼周肌肉收缩（鱼尾纹）。  |
| 惊讶    | 眉毛上扬、弯曲，眼睑张开，瞳孔放大，下颌下垂。   |
| 痛苦    | 哭泣，眼眉内角上扬，嘴角下拉，有节奏地啜泣。    |
| 恐惧    | 眼睛僵直、凝视，面色苍白，出汗，毛发竖立。     |
| 羞愧    | 眼神回避，头低垂，面部发红，伴有痛苦的表情。    |
| 轻蔑 - 厌恶 | 上唇抬起，鼻子皱起，可能伴有轻微的呕吐动作。    |
| 愤怒    | 眉毛下垂并聚拢，嘴唇紧张、可能张开露齿，面部发红。 |

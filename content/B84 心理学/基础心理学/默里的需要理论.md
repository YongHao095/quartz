## 概述

由美国心理学家亨利·默里于 1938 年在《人格探索》中提出。与马斯洛的 " 层次 " 理论不同，默里的理论更侧重于对人类需要进行的系统性**分类和描述**。他将需要定义为一种脑区的力量，能够组织知觉、统觉、智力、意志和行动，使某一原本不尽人意的情境朝着某个方向转化。该理论强调需要与**压力**（指环境中的刺激，非情绪压力）的相互作用，共同塑造人的行为。

## 种类

| 人类需要 | 描述                                 |
| :--- | :--------------------------------- |
| 谦卑需要 | 被动地屈从于外部力量，接受伤害、责备、批评和惩罚，投降与认输。    |
| 成就需要 | 克服障碍、施展才能、尽可能好地完成困难任务的驱动力。         |
| 亲和需要 | 寻求并建立友谊、与他人保持密切联系、参与愉快社交的驱动力。      |
| 攻击需要 | 有力地攻击对手、征服、复仇、乐于嘲笑或羞辱别人的驱动力。       |
| 自主需要 | 追求独立、摆脱约束、抵抗影响和 coercion、我行我素的驱动力。 |
| 避辱需要 | 避免失败、羞辱、嘲弄，因此回避可能带来失败情境的活动。        |
| 防御需要 | 保卫自己免受指责和批评，为自己的行为辩护、提供理由和证据。      |
| 恭敬需要 | 钦佩并愿意追随上级，乐于与领袖合作，有顺从的倾向。          |
| 支配需要 | 影响或控制他人，对他人负责，说服、禁止或指挥他人的驱动力。      |
| 表现需要 | 希望被注意、娱乐他人、使他人兴奋、震惊或感动，喜欢被关注。      |
| 避害需要 | 寻求安全，避免痛苦、身体伤害和疾病，采取谨慎行动以保安全。      |
| 免责需要 | 避免违反社会规则或法律，以保持行为清白和无过失。           |
| 教养需要 | 给予他人同情、关爱和帮助，滋养、帮助或保护弱者的驱动力。       |
| 秩序需要 | 安排、组织、整理事物，使其整洁、有序、干净利落的驱动力。       |
| 游戏需要 | 为了 " 好玩 " 而行动，寻求娱乐、放松、开玩笑、玩乐。          |
| 抵制需要 | 通过拒绝承认失败并再次努力来克服失败，为雪耻而奋斗。         |
| 感觉需要 | 寻求并享受感官印象和审美的愉悦体验。                 |
| 性需要  | 建立性关系，寻求并享受性爱和感官愉悦的驱动力。            |
| 求助需要 | 寻求帮助、保护或他人同情，表达自己的困境以求援助。          |
| 理解需要 | 乐于思考、提出和解决问题，热衷于分析和理论构建。           |

## 概述

情绪的理解，控制和利用的能力。

## 情绪智力的结构模型

1. 准确和恰当的知觉，评价和表达情绪的能力。
    1. 从自己的身体状态，感情与思想中确认情绪的能力。
    2. 通过语言，声音，外貌和行为，从他人，各种设计和艺术作品中确认情绪的能力。
    3. 精确表达情绪和与这些感情相关的需要的能力。
    4. 区分表情的精确性和真实性的能力。
2. 运用情感促进思维的能力。
    1. 将注意指向重要信息的能力。
    2. 产生生动和有效情绪的能力，从而帮助感情判断和记忆。
    3. 当心境从乐观转向悲观时，促使个体从多个角度考虑问题的能力
    4. 在不同情绪状态下，个体采用特定问题解决方法的能力。
3. 理解和分析情绪，有效地运用情绪知识的能力。
    1. 标识情绪和识别词和情绪本身关系的能力。
    2. 解释情绪所传递意义的能力。
    3. 理解复杂感情的能力。
    4. 识别情绪转换的能力。
4. 调节情绪，以促进情绪和智力发展的能力。
    1. 对各种感情保持开放心态的能力。
    2. 根据对信息的判断，操作情绪的能力。
    3. 自我控制自己和他人情绪的能力。
    4. 通过降低消极情绪和增强积极情绪，以调节自身和他人情绪的能力。


## 工作情商架构

工作情商可通过情绪胜任力问卷测量

1. 自我觉察
    1. 意识到自己情绪的变化：解读自己的情绪，认识情绪的影响。
    2. 精确的自我评估：了解自己的优点以及不足之处。
    3. 自信：掌控自身的价值及能力。
2. 自我管理
    1. 情绪自制力：能够克制冲动及矛盾的情绪。
    2. 坦诚：展现出诚实和正直的，值得信赖。
    3. 适应性：弹性强，可以适应变动的环境或克服障碍。
    4. 成就动机：具备提升能力的强烈动机，追求卓越的表现。
    5. 冲劲：随时准备采取行动，抓住机会。
3. 社会觉察
    1. 同理心：感受到其他人的情绪，了解别人的观点，积极关心他人。
    2. 团体意识：解读团体中的趋势，决策网络及政治运作。
    3. 服务：感知到客户及其他服务对象的需求，并有能力加以满足。
4. 人际关系管理
    1. 领导能力：以独到的愿景来引导及激励他人。
    2. 影响力：能说服他人接受自己的想法。
    3. 发展其他人的能力：通过回馈及教导来提升别人的能力。
    4. 引发改变：能激发新的做法。
    5. 冲突管理：减少相左意见，协调出共识的能力。
    6. 建立联系：培养及维持人脉。
    7. 团队能力：与他人合作的能力，懂得团队运作模式。

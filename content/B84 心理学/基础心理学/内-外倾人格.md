## 概述

由瑞士心理学家卡尔·古斯塔夫·荣格在其 1921 年出版的《心理类型》中提出。该理论旨在系统地解释和分类个体在感知世界、处理信息和做出决策时表现出的稳定差异。

## 理论

### 倾向

- **外倾**
    - **特征**：心理能量主要指向外部世界。
    - **表现**：兴趣和注意力集中于外在的他人、环境和活动；活泼、开朗、善于社交；从与人互动和外部事件中获得动力。
- **内倾**
    - **特征**：心理能量主要指向内部世界。
    - **表现**：兴趣和注意力集中于内在的思想、情感和体验；沉静、反思、喜欢独处；从内心的思考和反省中获得动力。

> [!tip]  
> 每个人都会使用两种倾向，但其中一种会占主导地位，成为优势倾向。

### 知觉功能

如何获取信息？

- **感觉**
    - **特征**：通过五种感官来感知事物的具体、实际的特征。
    - **表现**：此时此地、具体事实、细节、实际经验。" 我看到的事物本来就是那样的。"
- **直觉**
    - **特征**：通过无意识联想来感知事物的可能性、含义和内在联系。
    - **表现**：未来、模式、联系、灵感、第六感。" 事物背后隐藏的含义和可能性是什么？"

### 判断功能

如何做决定？

- **思维**
    - **特征**：基于逻辑、因果和客观分析来做决定。
    - **表现**：真假、对错、公平、客观标准。" 这个决定在逻辑上成立吗？"
- **情感**
    - **特征**：基于价值观和人际关系和谐来做决定。
    - **表现**：善恶、美丑、人际关系影响、个人价值观。" 这个决定对相关的人有什么影响？它值得吗？"

### 八种心理类型

荣格将两种态度与四种功能结合，描述了八种主导的心理功能类型

| 类型        | 核心特征描述                                                                |
| :-------- | :-------------------------------------------------------------------- |
| **外倾思维型** | 用客观、逻辑的法则来规范外部世界。常出现在科学家、律师中。可能显得固执、冷漠。                               |
| **内倾思维型** | 沉迷于内在的思想世界，追求观念的深度和逻辑自洽。常出现在哲学家、理论科学家中。可能忽视外部现实和他人情感。感情冷淡，独断偏执，易被人误解。 |
| **外倾情感型** | 对事物评价往往感情用事，凭借主观判断来衡量外界事物的价值                                          |
| **内倾情感型** | 情感深沉、强烈但不外露，拥有一个隐秘、丰富的情感世界。可能显得沉默、难以捉摸。                               |
| **外倾感觉型** | 追求感官刺激，遇事不假思索，随波逐流，善于应付现实，适应性强，活在当下。以具体事物为出发点，凭借感觉来估量生活的价值。           |
| **内倾感觉型** | 对感官刺激的主观印象异常深刻，关注内在的感觉体验，不能深入事物内部，在自己与事物之间常插入自己的感觉。可能显得安静、被动、艺术气质。    |
| **外倾直觉型** | 以主观态度探求各种现象，不接受过去的经验，善于发现外部世界的可能性和新的机会。只憧憬未来，容易悲观失望，可能兴趣多变，难以坚持。      |
| **内倾直觉型** | 专注于无意识的内在原型世界，产生神秘的预感和深刻的洞察。常出现在艺术家、预言家中。可能显得不切实际、疏离，脱离实际，喜欢幻想。       |
